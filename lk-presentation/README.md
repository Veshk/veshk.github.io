# Личный кабинет ВЭШ — интерактивная презентация

Сайт для отдела продаж и административного отдела. Публичная страница: https://veshk.github.io/lk-presentation/ . Рабочий кабинет: https://student.veshk.ru/login .

Срез содержания: **26 ноября 2026 года**. Это объяснение интерфейса, а не рабочий кабинет. Все люди, учебные примеры и показатели вымышлены. Будущая аналитика явно отделена от существующих функций.

## Что можно попробовать

- Состояния главной: доступ открыт, заявка на проверке, повторное обучение.
- Разделы группы: контакты, расписание, записи, материалы, запись на защиту.
- Выбор уроков, отметки прохождения, изменение прогресса, учебная обратная связь.
- Три схемы выдачи доступа и подсказки для двух отделов.
- Будущий отчёт: бесплатные, платные и все курсы; пояснение каждого этапа.
- Режим показа, переходы между главами, адаптация для телефона, сброс примеров.

## Запуск и проверка

Сборка и установка зависимостей не нужны. Из этого каталога:

```sh
python3 -m http.server 8097 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8097/ . ES-модули требуют HTTP; открывать `index.html` напрямую через file:// не следует.

```sh
node --check app.mjs
node --check model.mjs
```

Проверить сценарии выше на широком экране и на ширине 390 и 320 px. Кнопки доступны с клавиатуры; выбранные состояния обозначены `aria-pressed`; прогресс — `role=progressbar`; уменьшение движения поддержано.

## Данные и ограничения

Состояние существует только в памяти страницы и сбрасывается при перезагрузке. Нет API, хранилища, регистрации, платежей, отправки сообщений, аналитических трекеров или соединения с рабочей базой.

Учебная воронка: бесплатные `[100,70,42,25]`, платные `[40,36,26,20]`. Все — сумма **зачислений**, не уникальных людей. Этапы вложенные, проценты от открытых доступов. Период: первые 30 дней после открытия доступа для условной когорты 1–7 октября. «Начали» означает первую отметку урока, не просмотр видео. Пример 8 покупок из 100 человек за 60 дней — отдельная иллюстрация будущего анализа; он не вычисляется из воронки.

Шрифты Inter и изображения взяты из существующего публичного предпросмотра ЛК. Лицензия Inter в `assets/Inter-LICENSE.txt`. Оформление соответствует ЛК, а не полиграфическому шаблону ВЭШ.
