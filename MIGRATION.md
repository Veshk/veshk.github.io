# Куда перенесены файлы

Дата: **26 ноября 2026 года**, Екатеринбург.

Прежний репозиторий вместе с обеими ветками и историей сохранён как закрытый **[Veshk/student-portal](https://github.com/Veshk/student-portal)**. На прежнем адресе `Veshk/veshk.github.io` находится новый открытый репозиторий с проверенным снимком сайта. Публичные адреса страниц сохранены.

| Что было | Где теперь |

Имя `lk/real-course-content.js` и программный идентификатор `RealCourseContent` сохранены для совместимости страниц. Теперь этот публичный файл содержит демонстрационные ссылки. Его наличие не означает возврат рабочих данных.

Если ссылка на закрытый репозиторий показывает **404**, войдите в GitHub и запросите у владельца доступ именно к `Veshk/student-portal`. Публичность сайта не даёт доступа к серверной разработке.

## Как продолжать работу

Для существующего клона серверного проекта поменяйте адрес `origin`:

```sh
git remote set-url origin https://github.com/Veshk/student-portal.git
git fetch origin
```

Рабочая ветка серверного проекта — `codex/student-portal`, каталог — `student-portal/`. Неподтверждённые локальные правки сохраняйте; сбрасывать их ради переноса не требуется.

Для публикации открытого сайта создайте **новый клон**:

```sh
git clone https://github.com/Veshk/veshk.github.io.git veshk-public-site
```

Не делайте `merge` старой истории в новый открытый репозиторий и не отправляйте туда старые ветки через `--force` или `--mirror`. Нужные изменения переносите выборочно после проверки файлов. Обычная отправка старой истории в `main` или прежнюю серверную ветку будет отклонена из-за несовместимой истории.

## Проверка и откат

Команды проверки — в [README](README.md). Публичная копия не содержит историю до разделения. Для восстановления открытой страницы берите проверенный публичный коммит. Полные старые снимки доступны только в закрытом репозитории; возвращать их целиком в публичный доступ нельзя.

Разделение не переносит рабочую базу, сервер и службы и не меняет их настройки. Оно не отзывает копии, уже скачанные другими людьми. Старые приглашения и ссылки могут требовать отдельного отзыва у соответствующего сервиса; значения этих ссылок в этой карте не приводятся.
