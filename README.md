Этот репозиторий публикует статические страницы на [veshk.github.io](https://veshk.github.io/). Любой посетитель может прочитать и скачать его файлы.

В демонстрациях остаются программы и оформление ВЭШ, но ссылки на рабочие занятия, учебные чаты, записи и файлы заменены страницей с примером. Аккаунты и действия в прототипах не создают рабочие учётные записи, заказы или рассылки. Состояние сохраняется только в браузере. После разделения используется новый ключ локального хранилища, старые снимки с рабочими ссылками не загружаются.

## Разработка и проверка

Нужны Python 3 и Node.js 20 или новее. Запуск из корня:

```sh
python3 -m http.server 8091
```

Проверки:

```sh
node --test lk/tests/*.cjs utm/tests/*.mjs tests/*.cjs
python3 scripts/check-public-content.py
```

GitHub Pages публикует корень `main`. Изменения в `main` появляются на сайте после успешной сборки Pages. Публичная ветка `codex/student-portal` оставлена как указатель на перенос; серверной разработки в ней больше нет.

Не добавлять рабочие `.env`, базы, экспорты слушателей, токены, приглашения в учебные чаты, ссылки на закрытые материалы и серверный проект. Перед публикацией проверять не только интерфейс, но и содержимое коммита. Старые клоны нельзя объединять с новой публичной историей — используйте новый клон.
