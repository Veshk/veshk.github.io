# Генератор ссылок ВЭШ

Статическое приложение для GitHub Pages: `https://veshk.github.io/utm/`.

## Работа с приложением

1. Вставить адрес страницы.
2. Выбрать площадку и способ размещения.
3. Назвать материал, при необходимости выбрать шаблон, дату и вариант.
4. Скопировать готовую ссылку или скачать QR-код (PNG / SVG).

Названия на русском переводятся в латиницу. Ручные изменения в раскрывающемся разделе имеют приоритет над автозаполнением. Старые параметры `utm_*` заменяются, остальные query-параметры и якорь сохраняются. Небезопасные схемы, ссылки с логином/паролем и ошибочные повторные `?utm_` отклоняются.

История последних 100 скопированных ссылок и черновик сохраняются в localStorage текущего браузера. Историю можно искать, экспортировать в CSV, копировать и использовать повторно. Синхронизации с Google Sheets и общего серверного журнала нет. Удаление данных браузера удаляет локальную историю. Приложение не отправляет введённые ссылки сторонним API. QR формируется локально. Автоматического сокращения ссылок нет: на статическом хостинге для этого потребовался бы отдельный совместимый API или сервер.

## Разработка

Нужен только статический HTTP-сервер, например `python3 -m http.server 8766` из корня репозитория. Открыть `/utm/`. Сборка и установка пакетов не требуются.

Проверки ядра (Node.js 20+):

```sh
node --test utm/tests/engine.test.mjs
```

`data.mjs` — площадки, варианты размещения, список источников и названия шаблонов. `engine.mjs` — сборка ссылок, транслитерация, даты и экспорт. `app.mjs` — интерфейс и локальное хранение. `style.css` — адаптивное оформление.

## Источники оформления и правил

- Логотип, цвета `#B2272A`, `#226D8D`, `#6BA6C0`, шрифты Lato / Raleway взяты с публичного сайта https://veshk.ru/ для приложения ВЭШ.
- Список источников, типов трафика, префиксы кампаний и дата в `utm_content` перенесены из предоставленного генератора ВЭШ по состоянию на 28.10.2026. Существующая таблица не изменялась; личные записи из её журнала не публикуются.
- Сочетания в интерфейсе выбраны для типовых сценариев; доступны ручная правка и дополнительные источники. Для кампаний digest/sale/mono/corp месяц записывается как `YYYY_MM`, чтобы различать годы.
- `vendor/qrcode.js` и `vendor/qrcode-utf8.js`: qrcode-generator 1.4.4, Kazuhiko Arase, MIT. Уведомление о лицензии сохранено в исходных файлах; пакет получен из npm с проверкой SHA-512.

Публикация: файлы каталога `utm/` в основной ветке существующего GitHub Pages. Другие страницы репозитория не затрагиваются.
