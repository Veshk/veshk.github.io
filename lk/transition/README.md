# Прототипы страницы перехода в новый ЛК

Подготовлены 23 ноября 2026 года для последующего оформления в Tilda.

- `index.html` — обзор трёх вариантов.
- `cards.html` — обновлённый вариант: объявление о переходе, два входа и инструкция.
- `question.html` — выбор по ответу на вопрос о приглашении.
- `steps.html` — инструкция на первом плане.
- `styles.css`, `prototype.js` — оформление и локальные интерактивные элементы.

## Согласованный сценарий

Начало приглашений — 1 декабря 2026 года. Переходный период — декабрь 2026 и январь 2027. Это период перехода, а не обещание автоматического закрытия старого ЛК в определённую дату.

Студент переходит только после письма от школы. До приглашения использует старый кабинет. Аккаунт для переноса готовит школа; повторно регистрироваться студенту не требуется. По приглашению он создаёт пароль, входит с email из письма и открывает указанное обучение. Старый пароль автоматически не переносится.

Старый вход: https://lk.veshk.ru/members/login

Новый вход: https://student.veshk.ru/login

Помощь: online@veshk.ru

## Границы прототипа

Это общедоступные статические макеты с `noindex,nofollow`. Они не отправляют письма, не создают аккаунты, не меняют доступы и не связаны с базой слушателей. Кнопки входа ведут на настоящие страницы авторизации. Основной сайт Tilda и рабочий ЛК этой публикацией не изменяются.

Тексты описывают согласованный будущий переход. Перед запуском необходимо отдельно проверить рабочую отправку приглашения, создание пароля и выдачу правильного обучения. Сам по себе прототип не подтверждает готовность рассылки приглашений. Сценарий самостоятельной первичной регистрации новых студентов не изменяется этим макетом.

Первый вариант переработан 23 ноября по прямому запросу: сначала объявление «С 1 декабря переходим в новый личный кабинет». Композиция и типографика основаны на https://veshk.ru/mba-finance-director: Inter, тонкие разделители, прямоугольные кнопки. По последующему уточнению основная палитра, белый логотип, навигация шапки и подвал взяты с https://lk.veshk.ru/: фон #1a2b3b, зелёный акцент #10ba70, подвал #18252a. Горная фотография не используется, чтобы переход сохранял привычное оформление. `announcement.css` изолирован от других вариантов. В `assets/` находятся два подмножества Inter с публичного сайта школы, оригинальные белый PNG-логотип и SVG-значки социальных сетей из lk.veshk.ru. Шапка адаптируется на телефоне в меню, вопросы раскрываются без JavaScript. Остальные варианты сохраняют прежнее оформление Roboto.

## Локальная проверка

Из этой папки: `python3 -m http.server 8135 --bind 127.0.0.1`.

Открыть http://127.0.0.1:8135/ и проверить все три варианта, вопрос с тремя ответами, раскрытие вопросов и узкую ширину экрана. JavaScript: `node --check prototype.js`.

## Публикация и откат

Файлы размещаются только в `lk/transition/` статической ветки `main` репозитория Veshk/veshk.github.io. Публикацию выполняет существующий процесс GitHub Pages. Для отмены этой публикации достаточно отменить её коммит; остальные разделы и рабочие кабинеты не затрагиваются.
