# Публичный сайт ВЭШ

- Этот репозиторий и все его ветки публичны. Здесь только открытые статические страницы и очищенные демонстрации.
- Серверный проект, рабочие учебные ссылки и история до 26.11.2026 находятся в закрытом `Veshk/student-portal`. Сначала прочитайте `MIGRATION.md`.
- Не переносите старую Git-историю обратно, не выполняйте `push --mirror` или принудительную отправку из прежнего клона. Для открытой публикации используйте новый клон.
- Не добавляйте рабочие `.env`, ключи, пароли, базы, сведения о слушателях, приглашения в чаты, конференции с кодом доступа, прямые ссылки на рабочие записи и файлы.
- Сохраняйте публичные адреса разделов. Изменение демонстрации не даёт разрешения менять рабочий сервер.
- Перед публикацией: `python3 scripts/check-public-content.py` и `node --test lk/tests/*.cjs utm/tests/*.mjs tests/*.cjs` (Node.js 20+).
- При изменении устройства публикации обновляйте README и карту переноса. Документация на русском языке.
