# Студия ВЭШ — публичный прототип

Открыть: https://veshk.github.io/brand-studio/

В прототипе четыре раздела: библиотека дизайна, фирменный стиль, пилот комплекта мастер-класса и план сервиса. При открытии показывается библиотека дизайна. Обзор, каталог шаблонов, редактор материалов и черновики удалены из интерфейса и кода. Старые ссылки на удалённые разделы открывают библиотеку.

## Просмотр

Сборка не нужна. Из корня репозитория: `python3 -m http.server 8091`. Откройте `http://127.0.0.1:8091/brand-studio/`.

Фирменный стиль содержит логотипы, палитру, шрифтовые правила и базовую графику; прежний адрес `#brand` сохранён. Библиотека дизайна (`#library`) собирает иконки и графические элементы с правилами применения: зачем, когда использовать и когда не использовать, допустимые изменения, примеры, исходник и версия. Сейчас добавлен существующий фирменный мотив; наборы иконок, стрелок, линий и подчёркиваний ещё предстоит наполнить. Схемы категорий не являются утверждёнными исходниками, правила применения мотива пока не описаны. Пилот МК обновляет три эскиза по общим полям и позволяет скачать задание JSON. Данные формы сбрасываются при обновлении страницы; обратный импорт JSON не реализован. Рабочие сервисы и аккаунты не подключены.

## Публикация и проверка

Публикуется только демонстрация. Внутренние обсуждения, персональные назначения и закрытая техническая документация остаются в исходном проекте. Логотипы и мотив сохранены, интерфейс использует Inter; коммерческие файлы шрифтов не включены. Прежний адрес `about.html` перенаправляет в библиотеку.

Перед обновлением: `node --check brand-studio/studio.js`, проверки из корневого README и просмотр четырёх разделов в браузере. Проверить изменение темы и состояния регистрации в пилоте МК.
