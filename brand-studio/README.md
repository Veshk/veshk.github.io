# Студия ВЭШ — публичный прототип

Открыть: https://veshk.github.io/brand-studio/

Кликабельная демонстрация дизайн-центра: обзор, библиотека бренда, пилот комплекта мастер-класса, шаблоны, черновики и план сервиса. Подготовлена 26 ноября 2026 года.

## Просмотр

Сборка не нужна. Из корня репозитория: `python3 -m http.server 8091`. Откройте `http://127.0.0.1:8091/brand-studio/`.

Пользовательская справка: [О прототипе](about.html). Черновики сохраняются в текущем браузере под отдельным ключом `vesh-brand-studio-public-drafts-v1`. Рабочие сервисы и аккаунты не подключены. Экспорт JSON содержит задание, а не готовые изображения, PowerPoint или PDF.

## Публикация

Публикуется только демонстрация и её пользовательская справка. Внутренние обсуждения, персональные назначения и закрытая техническая документация остаются в исходном проекте. Логотипы и мотив сохранены, интерфейс использует Inter; коммерческие файлы шрифтов не включены.

Перед обновлением: `node --check brand-studio/studio.js`, проверки из корневого README и просмотр шести разделов в браузере.
